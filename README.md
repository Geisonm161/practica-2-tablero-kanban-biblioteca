# Biblioteca con estructura de pila

Aplicación de consola en C++ para registrar y consultar libros mediante una estructura de datos tipo pila (LIFO).

## Funcionalidades

- Registrar libros con título, autor, editorial, fecha y categoría.
- Listar los libros almacenados.
- Consultar y retirar el último libro agregado.
- Buscar libros por categoría conservando el contenido de la pila.

## Compilación

El proyecto incluye un `Makefile` y requiere un compilador compatible con C++:

```bash
make
./main
```
